# ThemePreset gallery

A Flutter gallery for the four `velora_ui` theme presets: aurora, meadow, neutral and corporate. Choose a preset, light or dark brightness, and standard or compact visual density to compare native Material widgets and the retained `velora_ui` components. The data destination demonstrates responsive sorting and selection.

From this directory, run `flutter pub get` and `flutter run`. Run `flutter test` to exercise the showcase.
