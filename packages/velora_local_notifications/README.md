# velora_local_notifications

On-device local notifications for Velora apps: a `LocalNotificationAdapter` over `flutter_local_notifications`.

Wired by hand as `Velora.boot(localAdapter: VeloraLocalNotificationsAdapter())`. `velora install velora_local_notifications` adds the dependency and prints the steps.

Requires Flutter >=3.47.0 / Dart >=3.13.0. Not published to pub.dev yet; use a git or path dependency.

Full guide: [`docs/packages/local-notifications.md`](../../docs/packages/local-notifications.md).
